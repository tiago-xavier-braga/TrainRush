# Train Rush

Rebuild a forgotten station into a thriving transport empire. Unlock trains, expand terminals, and keep the crowds moving before they walk out the door.

Arcade tycoon built in Unity, shipped for the web.

## Play it

[itch.io](https://xavigames.itch.io/) — playable in browser, no install.

## Tech

- Unity, C#
- [CrazySDK](https://sdk.crazygames.com/) for web platform integration (ads, save data, analytics)
- WebGL build target
